## 읽은 자료

## Apple이 말한 것 (WWDC25 전문)
- 재질의 핵심은 **lensing**: 빛을 "실시간으로 휘고, 모양 짓고, 집광"한다(이전 재질은 빛을 흩뿌림). 가벼움·투명함을 유지하면서 배경과 구분된다.
- 층: 기하에 반응하는 **하이라이트**(기기 움직임에도 반응), **그림자**(글자 위에서는 진해지고 밝은 단색 위에서는 옅어짐), **틴트/다이내믹 레인지**, 상호작용 시 **내부에서 발광**.
- 커질수록(버튼→메뉴) 그림자가 깊어지고 굴절이 뚜렷해지며 빛이 부드럽게 흩어진다.
- 작은 요소(탭바·내비바·심볼)는 배경에 따라 밝음/어두움이 **뒤집히고**, 큰 요소(메뉴·사이드바)는 적응하되 뒤집히지 않는다.
- Regular(적응형, 어디든) vs Clear(항상 더 투명, 미디어 위에서만, 디밍 층 필요). 섞어 쓰지 않는다.
- 쓰는 곳: **내용 위를 떠다니는 내비게이션·컨트롤 층**에만. 내용(표 등)에는 쓰지 않고, 유리 위 유리도 피한다. 모서리는 창 모서리와 **동심**(concentric)으로.
- 동작: 터치하면 "즉시 휘며 빛으로 충전", 빛은 **손끝 아래에서 시작해 요소 전체와 인접 유리로 번진다**. 요소는 "늘어나고, 튀고, 변형"한다. 메뉴는 버튼에서 "거품이 터지듯" 열린다. 나타날 때는 페이드가 아니라 **굴절·렌징을 점차 조절**하며 등장한다. 정지 상태는 조용하다.
- 스크롤 가장자리: 유리 아래로 내용이 "녹아들 듯" 사라진다.
- 접근성: 투명도 줄이기 = 더 뿌옇게, 대비 높이기 = 거의 흑백 + 테두리, **동작 줄이기 = 탄성 제거**.
- Apple은 블러 반경·스프링 상수·지속 시간 등 수치를 공개하지 않았다. 탭바 선택 유리의 미끄러짐·합침·분리 시간도 자료에 없다.

## 웹 재현 방법 (커뮤니티 자료, 저자 값)
- 기본 스택: `background:rgba(255,255,255,.15)` + `backdrop-filter:blur(2px) saturate(180%)` + `border:1px solid rgba(255,255,255,.8)` + `box-shadow:0 8px 32px rgba(31,38,135,.2), inset 0 4px 20px rgba(255,255,255,.3)`.
- 스페큘러: `inset 1px 1px 0 rgba(255,255,255,.75), inset 0 0 5px rgba(255,255,255,.75)`.
- 굴절(잡음형): `feTurbulence fractalNoise baseFrequency .008 numOctaves 2` → `feGaussianBlur 2` → `feDisplacementMap scale 70`.
- 굴절(물리형, kube.io): 가장자리 띠에서만 변위가 생기는 높이 함수(볼록 원·스쿼클·오목·립) → 법선 → 스넬 굴절(n 1→1.5) → RGB 변위 지도 → `feDisplacementMap`. 내부는 평평해 변위 0, 림에서만 렌징. Apple이 볼록 프로파일을 선호한다는 것은 kube의 추정.
- 한계: `backdrop-filter:url(#svg)`는 **Chromium만** 적용(Safari/Firefox는 블러 폴백). 요소 크기가 바뀌면 지도를 다시 만들어야 해 비용이 큼.

## 이 사이트의 구현 (src/refinement.css, src/liquid_glass.js, src/liquid_tabs.js)
- 유리 재질: 떠다니는 도구·메뉴·탭 트랙·언어 선택·카드 = 낮은 흰색 채움 + `blur(16px) saturate(190%)`; Chromium은 `url(#lgRefract)`(fractalNoise 변위 + 블러)로 굴절; 상단 1.5px 밝은 가장자리 + 안쪽 림 + hover 시 미끄러지는 사선 반사광. 내용 위 알약은 레이어 비용 때문에 반투명 + 가장자리광만(수십 개 backdrop 층을 피함).
- 터치: 누른 지점(`--press-x/--press-y`)에서 빛 고리가 퍼지고(380ms) 알약이 눌렸다 스프링으로 돌아온다(340ms). 동작 줄이기 설정이면 탄성 제거.
- 탭 트랙의 선택 유리(`liquid_tabs.js`): 선택 알약은 버튼과 분리된 한 장의 유리로, 선택이 바뀌면 **이동 방향으로 늘어났다가 스프링으로 자리 잡고**, 손가락/마우스로 **끌어서(스와이프)** 옮길 수 있으며 놓으면 가장 가까운 탭에 달라붙어 그 탭을 선택한다. 적용: 작업 영역 탭, 연구 도구 탭, 구조 칩, Study 단계.
- 모서리: 한 줄 컨트롤은 캡슐, 여러 줄 컨트롤(Study 단계 카드)은 18px 동심 둥근 사각형.
- 메뉴는 헤더 안에 있어 2차 backdrop 블러가 페이지에 닿지 않으므로 93% 흰 유리 + 페이지 디밍.
- 전환 시간은 Apple 수치가 없어 200–320ms(메뉴·도구 220, 카드 260)로 정했다. 내장 브라우저 실제 클릭 측정에서 끊긴 프레임 0.
