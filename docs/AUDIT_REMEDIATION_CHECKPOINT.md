# 감사 개선 — 사용량 제한에 따른 중간 중단 기록

후속 재개: 사용자의 “진행하자” 요청으로 [이미지 분석 자동 복구와 교체 보호](ANALYSIS_RECOVERY.md)를 구현했다. 아래 내용은 앞선 소규모 중단 기록이며 최신 상태는 후속 문서를 우선한다.

기준: 2026-11-04 (한국시간). 사용자 요청은 남은 사용량 범위에서 제한된 작업을 완료하고, 충전 후 재개하는 것이다. 처음 8%, 후속 요청 시 5%가 남았다는 사용자 안내에 따라 작은 수정 묶음 두 개를 선택했다. 실제 잔여 사용량은 도구로 측정할 수 없다. 큰 후속 기능은 시작하지 않았다.

## 1차 범위 — 모델 선택 (커밋 7180c94)

- A02: 잘못된 모델 교체가 거부될 때 파일 선택창과 실제 활성 모델을 함께 비운다. 이전 모델로 새 분석이 실행되지 않도록 생성 버튼도 비활성화한다.
- A06 일부: 학습 모델만 선택 해제하는 텍스트 버튼을 추가한다. TIFF와 기존 ROI/측정/승인/원래 예측의 출처는 그대로 유지한다.
- UX-02 일부: 모델 입력이 호환 학습 결과 JSON을 받는다는 안내를 추가하고, 새 문구를 5개 언어로 제공한다.
- 모델 처리나 다른 작업 진행 중에는 해제 버튼을 비활성화한다. 실행 중단과 선택 해제는 서로 다른 동작이다.

## 2차 범위 — 미적용 입력 보호 (A05)

- ROI·윤곽·꼭짓점 선택 및 영상 위 ROI 클릭이 미적용 좌표나 제외 사유를 덮어쓰지 않도록 공통 보호 조건을 추가했다.
- 미적용 경계·제외 변경이 있으면 현재 선택과 입력을 유지하고, 기존 적용/변경 취소 기능을 먼저 사용하도록 안내한다. 안내는 5개 언어로 제공한다.
- 메타데이터만 입력 중이면 ROI 이동을 허용하면서 해당 입력은 유지한다. 원자료·측정 계산·승인 기록을 이 선택 보호 기능에서 수정하지 않는다.
- 새로고침·탭 종료·이미지/예측 교체·ROI 재생성 보호나 자동 임시저장은 별도 미완료 항목이다. A05의 선택 변경 보호를 전체 작업 보존 완료로 해석하지 않는다.

## 완료 판정

구현, 검증, 배포를 따로 기록한다. A06/UX-02 전체를 완료 처리하지 않는다. 이미지/예측/관찰 자료의 개별 첨부 해제, 통합 입력 설계, 기본 모델 공급은 미완료다. 모델 크기 제한 UI16MiB/코어64MiB 불일치(A11)도 이번 범위가 아니다.

배포 상태: **미배포**. 이 수정은 `work/audit-model-selection-checkpoint` 브랜치의 재개용 체크포인트다. 운영 사이트는 기존 v21을 유지하며, 다음 재개 때 관련 개선을 연결하고 릴리스 검증 후 배포한다.

## 검증 기록

**A02 구현·범위 내 검증 완료, 미배포. A06/UX-02는 모델 입력 부분만 구현·검증 완료.** Chromium 10개 검사 통과, 브라우저 오류·외부 요청·업로드 없음. 분석 코어 검사 통과, 과학 데이터 파일 9개 해시 불변 확인. 별도 결과 `qa/model-selection-checkpoint.json`을 참조한다. 분석 코어의 기존 검증과 실제 Chromium 모델 UI 검증을 사용한다. 합성 자료로 상태·승인·내보내기를 검사하며 실제 Nissl 분할 정확도나 Safari 성능을 입증하지 않는다. 전체 31개 릴리스 suite는 이번 제한 작업에서 다시 실행하지 않는다.

**A05 구현·범위 내 검증 완료, 미배포.** `node qa/check_analysis_browser.cjs`의 Chromium 13개 검사 그룹이 통과했다. 좌표 입력과 제외 설정 입력을 각각 ROI·윤곽·꼭짓점 선택(키보드 포함) 및 실제 캔버스 클릭의 7개 경로로 검사했다. 선택·미적용 입력·검토 스냅샷 보존, 미적용 중 승인/내보내기 차단, 명시적 변경 취소 후 이동, 메타데이터 입력 보존, 기존 적용·드래그·승인·원본 포함 ZIP 내보내기·초안 재열기를 확인했다. 브라우저 오류·외부 요청은 없었고 320px 화면 검사도 통과했다.

2차 결과는 `qa/selection-guard-checkpoint.json`에 분리 보관했다. 빌드·JavaScript 문법 검사 통과, 과학 데이터 파일 9개 해시 불변, 소스와 빌드 파일 일치, 경고 문구 5개 언어 키 존재를 확인했다. 이번에는 언어별 브라우저 표시·전체 과학 검산 suite·Safari·실제 Nissl 정확도를 재검증하지 않았다. 기존 릴리스 보고서와 화면 캡처는 덮어쓰지 않았다.

## 다음 재개 지점

1. 이 브랜치와 현재 main의 변경을 확인한다. 운영 사이트에 반영됐다고 가정하지 않는다.
2. A03/A04/DATA-01~03: 자동 임시저장·복구, 연구/이미지/예측 교체 및 ROI 재생성 시 저장된 검토 보호, 미적용 입력·최신 입력의 저장 일관성을 우선 처리한다.
3. A06/DATA-07~09: 나머지 파일 종류의 개별 해제, 다중 탭·다른 주석 화면의 키보드 보호를 확장한다. A05의 이미지 분석 선택 보호와 별개다.
4. SCI-01/02: 중복 원본 비교 차단과 원본 근거 등급·승인 정책을 연결한다.
5. UX-04~06/E01~02: 개인 작업을 예제 데이터 로딩에서 분리하고, 시작 실패·시간제한·초기 다국어를 개선한다.
6. 나머지 62개 감사 항목은 본 보고서와 기존 계획대로 이어간다. 원자료·결측값·제외 사유·기존 측정 기준을 보존하며, 과학적 검증·외부 자료/권리 대기는 별도 표시한다.

코드 수정과 QA 준비를 병렬로 수행했으며, 사용량 절약을 위해 독립적인 대형 개발을 추가로 시작하지 않았다.
