# ROI 자동화·분리 저장·3D 개발 검토 — 2026-11-05

이 문서는 v27 이후 사용자 요청에 대한 구현 범위다. 검증·배포의 최종 실행 결과는 같은 릴리스의 `qa/release-validation.json`, `qa/release-index.json`, 배포 영수증을 확인한다. 소프트웨어 구현 완료와 실제 소뇌에서의 예측 정확도는 별도로 판정한다.

## 결과물과 사용 순서

1. 시작 화면에서 **새 montage 열기**. 이미 학습한 모델을 이 브라우저에 보관했다면 다시 선택할 필요가 없다. 처음에는 자동 ROI 도구로 본인의 검토 원본을 학습하고 `auto-roi-models.json`을 연다. 새 montage에 기존 ROI는 필요하지 않다.
2. **ROI만 확인**에서 배경 없이 경계를 검토한다. 전체·조직 라벨·개별 ROI 범위를 선택할 수 있다. 원본 예측이 너무 복잡하면 **편집 가능한 후보 만들기**에서 명시적인 근사 변환을 선택한다. 변경 픽셀 수와 원본 분류 지도를 함께 보관한다. 기존 검토를 덮어쓰려면 교체 결과를 확인한다.
3. 경계·축척·절편 정보를 확인하고 승인한 뒤 **measurement.csv**, **result.csv**, **ROI.zip**을 각각 저장한다. CSV는 ROI별 면적·선 길이·점 개수를 구분하며 알 수 없는 물리 단위 값은 비워둔다. 전체 증거 ZIP에는 원본·모델·검토 이력도 보관한다. 일부 ROI만 저장하더라도 승인은 전체 검토 상태와 연결된다.
4. 승인한 절편을 Study로 이어서 기존 동물에 차례로 추가하고 실제 축척·Z·정렬 정보를 확인한다. 두 개 이상 절편에서 조직, 정확한 주석 이름 또는 학습된 피질 소엽 영역을 선택한다. 관측된 좌표 CSV와 추론된 표면 OBJ를 구분해 저장한다. PL 선에는 관측된 선만 표시하고 면·부피를 만들지 않는다.

## 요구사항별 구현과 증거 한계

| 목표 | 구현된 동작 | 아직 입증되지 않은 내용 |
|---|---|---|
| CB·ML·GL·WM 자동 ROI | 실제 원본을 학습하는 두 모델과 새 TIFF 자동 예측, 검토·편집 | 본인의 5마리 데이터로 학습된 실제 가중치와 새 절편의 생물학적 정확도 |
| PL 자동 후보 | 사용자가 선택하면 예측 ML–GL 공유 경계를 열린 선으로 추출. 분기와 길이 보존 | Purkinje 세포 자체의 검출 또는 해당 선이 PL임을 확인한 결과. PL 면적 주석을 선 길이로 변환하지 않음 |
| 소엽별 자동 후보 | 학습 개체의 ML/GL 이름 주석으로 선택적 소엽 모델 학습. 명명된 피질 영역으로 보관 | WM을 포함한 전체 소엽 분할, atlas 기반 식별, 외부 개체에서의 정확도 |
| 개별 분석·저장 | 전체·선택 조직·개별 ROI 보기와 세 파일 개별 저장. 제외·교정·승인 상태 보존 | 서로 겹치는 CB·층·소엽 면적의 합을 독립 조직량으로 해석하는 기능은 제공하지 않음 |
| 3D 구조 | 실제 물리 좌표의 관측 절편과 보간 표면, 명명된 영역별 보기, CSV/OBJ | 단일 montage로 전체 소뇌를 복원한 결과, 잃어버린 절편의 관측값, 등록되지 않은 절편의 해부학적 대응 |
| 간결한 UI | 흑백 카드, 중요한 작업 버튼, 접힌 상세 안내, 메뉴 hover/focus 배경 blur, 좁은 화면·키보드·터치 대응 | 실제 연구자의 시간 절약 수치와 장기 사용성 실험 |

기존 2개 모델 묶음은 그대로 동작한다. 그 파일에 소엽 모델이 없다면 소엽 결과를 만들어내지 않는다. 새 도구로 원본을 다시 학습하면 유효한 명명 주석이 있는 경우에만 소엽 모델을 추가한다. 모델의 픽셀 특징은 국소 영상 특징이며 atlas나 공간 정합 모델이 아니다. 결과는 연구자가 확인해야 하는 실험적 초안이다.

## 정량·정성 평가

- 자료 확인: **5마리, 66절편**의 확정된 최종 CRA ROI 계획. ML 소엽 면 주석 439개, GL 소엽 면 주석 436개, 원문 표기가 다른 소엽 토큰 17개. Fl/FI 및 PFl/PFI는 임의 병합하지 않는다.
- PL_TOTAL: **51개 선, 15개 면**. 소엽별 PL은 선 425개, 면 12개. 종류가 다른 주석은 동일한 길이 정답으로 취급하지 않는다.
- 산출물: 요청한 **3개 파일 형식**의 독립 저장 경로. 분석량은 면·선·점을 구분하며 승인·원본 SHA와 연결한다.
- 기능 평가: 위 6개 개발 항목에 실행 경로가 마련되었다. 다만 PL은 경계 후보이고 소엽은 주석된 피질 영역이므로 **6개 항목 모두의 해부학적 목표가 완성되었다는 뜻은 아니다**.
- 실자료 성능 평가: 이 환경에는 원본 TIFF와 사용자 학습 모델이 없어 새 montage의 Dice·경계 오차·절약 시간을 계산하지 않았다. 근거 없는 전체 완성률이나 정확도 백분율은 제시하지 않는다.
- 다음 검증 단위: 사용자 학습 모델로 추론한 별도 절편을 개체별로 평가하고, PL 후보와 실제 PL의 거리/길이 오차, 피질 소엽의 정밀도·재현율, 편집 소요 시간을 기록한다. 현재 고정 내부 평가 분할은 완전한 독립 생물학적 검증을 대신하지 않는다.

프로그램은 파일 연결·해시 검증·학습·초안·변환 이력·측정·내보내기를 담당한다. 연구자는 실제 생물학적 경계와 알려진 실험 메타데이터를 확인한다. 보고서 업로드나 JSON 수정을 반복하게 하는 절차는 정상 사용 경로에 포함하지 않는다.
