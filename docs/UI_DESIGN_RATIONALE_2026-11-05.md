## 자료와 적용 범위

- Rosenholtz, Li & Nakano (2007), Measuring visual clutter, Journal of Vision 7(2):17, DOI 10.1167/7.2.17. 시각적 복잡도를 측정하는 연구 배경으로 참고했다. 이 제품에서는 기능별 그룹, 제한된 강조색과 넓은 그룹 간격을 선택했다. 이 논문이 특정 px 간격이나 이 제품의 생산성 증가를 검증한 것은 아니다. https://pubmed.ncbi.nlm.nih.gov/18217832/
- Heer & Robertson (2007), Animated Transitions in Statistical Data Graphics, DOI 10.1109/TVCG.2007.70539. 데이터 그래픽 전환의 지각 효과에 대한 연구다. 카드 UI에 대한 직접 실험은 아니며, 선택 위치와 중앙 카드의 연속성을 보여 주는 설계에 제한적으로 참고했다. https://idl.uw.edu/papers/animated-transitions
- W3C WAI modal dialog pattern: 모달 내부 포커스, Escape, 배경 비활성화와 닫은 뒤 포커스 복귀. https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/
- WCAG 2.2 SC 2.3.3: 비필수 상호작용 모션을 줄일 수 있도록 한다. OS 모션 감소 설정을 존중하고 자동 넘김·과도한 반복 효과를 사용하지 않는다. https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html

## 구현 판단

기능 내부보다 기능 사이 간격을 크게 두고 제목·주요 행동·상세 안내의 강약을 구분한다. 설명은 필요한 순간에 여는 중앙 카드로 제공한다. 안내 카드 계열은 동일한 반응형 외곽 크기를 사용하고 내용은 내부 스크롤한다. 읽기·닫기·이전·다음이 화면 밖으로 사라지지 않아야 한다.

UI 30의 카드 확장 300ms·내용 전환 220ms는 UI 31에서 각각 440ms·300ms로 늘렸다. 작업 공간과 메뉴 전환은 360ms다. 이는 조정 가능한 설계값이며 심리학이 입증한 최적값이라는 주장은 하지 않는다. 연구 입력·파일·캔버스는 복제하지 않는다. 상세 창을 위해 잠시 공통 컨테이너로 감싸는 실제 노드는 닫을 때 같은 부모와 순서로 복원한다.

검사는 데이터 보존, 카드 크기 일치, 키보드·모션 감소, 320/768/1440px 레이아웃, 확대에 해당하는 작은 CSS 뷰포트, 다국어, 운영 배포 파일 일치로 수행한다. 사용자 대상 사용성 실험이나 실제 Mac Safari 검증을 대신하지 않는다. 후속 사용자 평가에서는 경로 찾기 시간·작업 성공률·오조작을 비교한다.
