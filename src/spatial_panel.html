Adjusting the spacing changes only the on-screen layout; actual Z coordinates are unchanged. XY and Z are scaled separately, so the 3D view does not preserve physical proportions. Rotation is about the bounding-box centre of each original section.

Comparison of interpolation results for the virtual arrangement

Observed planes are held out and interpolated separately in the original and virtual arrangements. Because changing the arrangement also changes the positions being evaluated, the difference between the two scores cannot be interpreted as an improvement in anatomical accuracy. Virtual exclusion also changes the number of evaluated sections.
